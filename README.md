# Web Programming Projects - 2nd Year University

This repository contains a collection of web development projects developed during the 2nd year of University. Each folder represents a laboratory assignment focusing on different web technologies, from basic HTML to server-side PHP and AJAX.

## 🚀 Lab Overview

### [Lab 1: Pure HTML](Lab_1/)
*   **Objective:** Create a valid HTML5 page using only basic HTML language.
*   **Requirements:** No CSS or JavaScript allowed. Use of specific tags like `<table>`, `<svg>`, `<audio>`, `<video>`, and structural elements (`<header>`, `<footer>`, `<article>`, etc.).
*   **Theme:** Personal interest page (Nature/Sounds).

### Lab 2: Advanced CSS & Cloning
*   **[Yahoo Clone](Lab_2/):** Recreating approximately 90% of a screen from Yahoo.com using only HTML and CSS.
*   **[CSS Animations](Lab2_MI/):** 3D bouncing cube and interactive ball animation.

### [Lab 3: JavaScript Interactivity](Lab3_JS/)
*   **Objective:** Dynamic image gallery.
*   **Feature:** Implementing a thumbnail preview system where hovering over a small image displays the full-sized version dynamically.

### [Lab 4: jQuery & Dynamic Loading](Lab4_Jquery/)
*   **Objective:** Implementing "Infinite Scroll" using jQuery.
*   **Feature:** Detecting page bottom and dynamically appending new content blocks with a simulated network delay and a "Loading..." message.

### [Lab 5: Full-Stack Web App (PHP & AJAX)](Lab_5/)
*   **Objective:** URL Management System.
*   **Features:**
    *   **Backend:** PHP with MySQL database (CRUD operations).
    *   **Frontend:** AJAX for asynchronous data fetching and pagination (4 URLs per page).
    *   **Security:** Prevention of SQL Injection and basic authentication (Login system).
    *   **UX:** Category-based grouping and confirmation modals for actions.
